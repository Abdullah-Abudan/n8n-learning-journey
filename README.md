# n8n Learning Journey

This repository is where I document my journey learning n8n through hands-on experiments and projects.

I'm using it to practice building workflows, try different integrations, understand how things work, and learn from the problems I face along the way.

## Projects and Experiments

### 1. Telegram AI Chatbot

My first experiment with n8n and AI. I built a Telegram bot that uses an AI model through OpenRouter to reply to messages.

- [View the project](./n8n-telegram-ai-chatbot/README.md)

### 2. Restaurant Order & Inventory Management — Learning Exercise

An earlier n8n exercise based on Engineer Kareem Nabil's lessons 009 and 010. It combines order entry, Telegram updates, Google Sheets, and basic stock handling in one workflow. This is separate from RestaurantFlow, which is documented as its own later project.

- [View the learning exercise](./learning-exercises/restaurant-order-inventory/README.md)

### 3. RestaurantFlow — Order & Inventory Automation

A restaurant order management project built with n8n, Telegram, and Google Sheets.

It connects three workflows to handle incoming orders, manage order statuses, and track ingredient inventory. The goal is to automate the process from receiving an order to checking stock and recording inventory changes. The project also includes a test plan with 17 test cases and screenshots documenting key steps and results.

- [View the project](./restaurant-order-inventory-automation/README.md)

I'll add more experiments as I learn and build new things.
